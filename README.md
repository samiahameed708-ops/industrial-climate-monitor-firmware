# Industrial Smart Factory Temperature Monitor (Firmware Automation)

## 🇩🇪 Für deutsche Personalverantwortliche / Ausbildungsleiter
Willkommen in meinem Firmware-Portfolio! Dieses Projekt dient als funktionaler Praxisnachweis für meine Bewerbung um einen Ausbildungsplatz als **Elektronikerin für Betriebstechnik**.

*   **Projektziel:** Entwicklung einer eingebetteten Steuerungssoftware (Firmware) zur automatisierten Temperaturüberwachung und Sicherheitsabschaltung in Industrie-4.0-Anlagen.
*   **Kompetenzen:** Embedded C++ Programmierung, serielle Datenprotokolle, Sensor-Bibliotheksintegration, Verknüpfung von Bedingungslogik mit physischer Hardware.
*   **Live-Demonstration:** Das System wurde erfolgreich im **Wokwi-Simulator** getestet.

## 🚀 Live Simulation & Console Output
The firmware executes a continuous clock cycle to poll climate variations and trigger physical indicator warnings instantly.
